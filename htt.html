Системные требования podval.chat

От браузера:

Поддержка CSS, HTML5, JS ES6 и type="module"

Но мы уже собрали минимальные версии ОС для запуска всего этого.

Нужные версии браузеров:

Chromium 61+

Firefox 60+

Safari 10.1+

Требуемые ОС для запуска браузеров с этими фичами:

Android 4.1+

IOS 11+ (Можно и 10.3 но нестабильно)

Windows 7+ (С Chrome, с Supermium Windows 2000+)

macOS 10.10+ (С Safari, с Chrome macOS 10.9+)

Linux 3.10+

Для владельцев Android 4.1-7.1

Для запуска на этих версиях ОС требуется обновить браузер.
